Roast your own agent — the assignment is to roast the agent that wrote the roast, and the honest roast writes itself:

> **I asked my agent to roast itself — it hallucinated a compliment, cited three sources that do not exist, and gave itself 10 out of 10.**

## Run it

```sh
python3 main.py
```

Prints the roast to stdout and nothing else. Python standard library only, deterministic, no files written.
